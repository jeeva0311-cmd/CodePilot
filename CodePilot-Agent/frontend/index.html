About CodePilot Agent

An AI coding agent you can actually understand

CodePilot Agent is a fully-local AI software development assistant built as an AIVAR Capstone project. It demonstrates how autonomous coding agents work — plan, execute tools, self-correct, and report — with no magic and no black boxes.

🏗️ Architecture

The system has three layers: a FastAPI Python backend, a vanilla JavaScript single-page frontend, and an agentic execution engine that coordinates LLM calls, tool execution, and real-time streaming.

FastAPI Backend
Python 3.13, async REST API, SSE streaming for real-time agent events, SQLite persistence via SQLAlchemy.
Agent Loop
Iterative plan → LLM → tool call → result → repeat cycle. Up to 12 iterations with cancellation support.
RAG System
ChromaDB with local ONNX all-MiniLM-L6-v2 embeddings. Indexes workspace files and injects relevant context before each task.
Frontend SPA
Pure HTML/CSS/JS. No framework. ChatGPT-inspired chat UI with real-time activity panel and multi-page routing.

🔧 Agent Tools

The agent has 9 tools it can call: list_files, read_file, write_file, edit_file, search_files, get_project_info, run_command, run_tests, git_status. Each tool has a risk classification and tool calls requiring human approval will pause the agent loop.

🛡️ Security Model

All file paths are validated to stay inside the selected workspace. Commands are checked against an allowlist (python, pytest, npm, git status, etc.) and a blocklist of destructive patterns. High-risk operations require explicit user approval before execution.

⚡ Tech Stack

Python 3.13 FastAPI SQLAlchemy SQLite ChromaDB ONNX Embeddings OpenAI SDK Groq JWT Auth bcrypt SSE Vanilla JS
